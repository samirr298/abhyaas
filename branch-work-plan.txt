ABHYAAS BRANCH WORK PLAN

Purpose:
- Use one branch per user story so each person can work separately without overwriting each other's changes.
- Keep frontend, backend, testing, and validation work small and easy to review.

How we will work:
1. Create or checkout the correct branch.
2. Do only the task assigned to that branch.
3. Test locally.
4. Commit with a clear message.
5. Push the branch to GitHub.
6. Open a pull request when the branch is ready.
